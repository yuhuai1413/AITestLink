## 一、本地开发环境

### 1.1 环境要求

| 组件 | 要求 |
|------|------|
| Python | 3.10+ |
| Node.js | 18+ |
| 包管理器 | pnpm |

### 1.2 启动后端

```bash
cd server

# 创建虚拟环境（首次）
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 启动服务
uvicorn app.main:app --reload --port 8001
```

### 1.3 启动前端

```bash
cd frontend

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

### 1.4 运行测试

```bash
# 后端测试
cd server
python -m pytest tests/ -v

# 前端测试
cd frontend
npx vitest run
```

## 四、首次部署

### 4.1 服务器初始化

```bash
# SSH 登录服务器
ssh root@116.62.247.82

# 创建项目目录
mkdir -p /opt/aitestlink

# 安装 Node.js（如未安装）
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs

# 安装 pnpm
npm install -g pnpm

# 安装 Python 虚拟环境（如未安装）
apt-get install -y python3-venv python3-pip

# 创建 Python 虚拟环境
cd /opt/aitestlink/server
python3 -m venv venv
source venv/bin/activate

# 安装后端依赖
pip install -r requirements.txt
pip install bcrypt gunicorn
```

### 4.2 同步代码到服务器

```bash
# 在本地执行
rsync -avz --delete \
  --exclude 'node_modules' \
  --exclude '.git' \
  --exclude 'dist' \
  --exclude '.vite' \
  --exclude 'venv' \
  --exclude '*.db' \
  --exclude 'server/uploads/' \
  /Users/yuhuai/AI-APP/CodeX/AITestLink/ \
  root@116.62.247.82:/opt/aitestlink/
```

### 4.3 配置后端环境变量

在服务器上编辑 `/opt/aitestlink/server/.env`：

```bash
# 数据库（SQLite，无需额外安装）
DATABASE_URL=sqlite+aiosqlite:///./aitestlink.db

# LLM API 配置（按实际使用的模型填写）
LLM_API_KEY=your-api-key-here
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o

# 文件上传目录
UPLOAD_DIR=./uploads

# 跨域配置（独立域名）
CORS_ORIGINS=https://aitestlink.cn,http://aitestlink.cn

# JWT 密钥（必须修改为强随机字符串）
JWT_SECRET=your-production-jwt-secret-here

# 后端基础 URL
BASE_URL=http://localhost:8001
```

### 4.4 构建前端

```bash
# 在服务器上执行
cd /opt/aitestlink/frontend

# 安装依赖
pnpm install

# 构建前端（独立域名，base 为 "/"）
pnpm build
```

> 当前项目已修复前端类型构建链路，部署时应使用 `pnpm build`，确保 TypeScript 和 Vite 构建同时通过。

### 4.5 启动后端服务

```bash
# 在服务器上执行
cd /opt/aitestlink/server

# 确保 venv 中安装了 gunicorn
/opt/aitestlink/server/venv/bin/pip install gunicorn bcrypt

# 使用 PM2 启动
pm2 start gunicorn \
  --name aitestlink-server \
  --bind 0.0.0.0:8001 \
  --workers 4 \
  --worker-class uvicorn.workers.UvicornWorker \
  --chdir /opt/aitestlink/server \
  -- venv/bin/python -m app.main:app

# 或者使用 uvicorn 直接启动（开发/调试用）
pm2 start /opt/aitestlink/server/venv/bin/uvicorn \
  --name aitestlink-server \
  -- app.main:app \
  --host 0.0.0.0 \
  --port 8001 \
  --reload

# 保存 PM2 进程列表（开机自启）
pm2 save
pm2 startup
```

> **重要**：gunicorn 的 `--chdir` 必须指向项目根目录，worker 命令使用 venv 中的 Python 路径。

### 4.6 配置 Nginx

创建独立配置文件 `/etc/nginx/sites-available/aitestlink`：

```nginx
server {
    listen 80;
    server_name aitestlink.cn www.aitestlink.cn;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name aitestlink.cn www.aitestlink.cn;

    ssl_certificate /etc/letsencrypt/live/aitestlink.cn/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/aitestlink.cn/privkey.pem;

    # 前端静态文件
    location / {
        root /opt/aitestlink/frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;

        # 静态资源缓存
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
            expires 30d;
            add_header Cache-Control "public, immutable";
        }
    }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://127.0.0.1:8001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # AI 请求可能耗时较长
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }

    # 上传文件访问
    location /uploads/ {
        alias /opt/aitestlink/server/uploads/;
        expires 7d;
        add_header Cache-Control "public";
    }
}
```

启用站点并重载：

```bash
ln -sf /etc/nginx/sites-available/aitestlink /etc/nginx/sites-enabled/aitestlink
nginx -t && nginx -s reload
```

## 七、常见问题排查

### 7.1 前端刷新 404

**原因**：Nginx 未配置 `try_files` 回退到 `index.html`。

**解决**：确保 location 配置中有：
```nginx
try_files $uri $uri/ /index.html;
```

### 7.2 API 请求 404

**原因**：Nginx 未正确代理 `/api/` 路径，或后端未启动。

**解决**：确认 Nginx 有 `/api/` location 块且 `proxy_pass` 指向 `http://127.0.0.1:8001`。

### 7.3 登录页面验证码不显示

**原因**：前端 API 地址没有通过统一的 `shared/config/deploy.ts` 推导，或生产构建 base 配置错误。

**解决**：确认 `frontend/src/features/auth/api/client.ts` 使用统一 API 地址：
```ts
import { API_BASE } from "../../../shared/config/deploy";
const BASE_URL = API_BASE;
```

### 7.4 后端启动报 bcrypt 找不到

**原因**：bcrypt 安装到了系统 Python 而非 venv。

**解决**：
```bash
/opt/aitestlink/server/venv/bin/pip install bcrypt
```

### 7.5 CORS 跨域错误

**原因**：`.env` 中 `CORS_ORIGINS` 未包含生产域名。

**解决**：
```env
CORS_ORIGINS=https://aitestlink.cn,http://aitestlink.cn,http://localhost:5173
```

### 7.6 部署后代码不是最新版

**原因**：同步了错误的本地目录。

**解决**：确认本地源码目录为 `/Users/yuhuai/AI-APP/CodeX/AITestLink`（CodeX 目录），而非其他副本。同步前可对比 git log：
```bash
cd /Users/yuhuai/AI-APP/CodeX/AITestLink && git log --oneline -5
```

### 7.7 vite.config.js 覆盖 vite.config.ts

**原因**：服务器上残留了旧的 `vite.config.js` 文件，优先级高于 `.ts`。

**解决**：
```bash
cd /opt/aitestlink/frontend
rm -f vite.config.js vite.config.d.ts
```

## 八、一键部署脚本（可选）

项目自带 `scripts/deploy.sh`，也可使用以下完整脚本：

```bash
#!/bin/bash
set -e

SERVER="root@116.62.247.82"
REMOTE_DIR="/opt/aitestlink"

echo ">>> 1. 同步代码到服务器..."
rsync -avz --delete \
  --exclude 'node_modules' \
  --exclude '.git' \
  --exclude 'dist' \
  --exclude '.vite' \
  --exclude 'venv' \
  --exclude '*.db' \
  --exclude 'server/uploads/' \
  ./ \
  ${SERVER}:${REMOTE_DIR}/

echo ">>> 2. 服务器上构建前端..."
ssh ${SERVER} << 'EOF'
cd /opt/aitestlink/frontend
rm -rf dist .vite node_modules/.vite
pnpm install --frozen-lockfile 2>/dev/null || pnpm install
pnpm build
EOF

echo ">>> 3. 服务器上更新后端依赖..."
ssh ${SERVER} << 'EOF'
cd /opt/aitestlink/server
/opt/aitestlink/server/venv/bin/pip install -r requirements.txt
/opt/aitestlink/server/venv/bin/pip install bcrypt gunicorn
EOF

echo ">>> 4. 重启后端服务..."
ssh ${SERVER} "pm2 restart aitestlink-server"

echo ">>> 5. 验证..."
ssh ${SERVER} "curl -s https://aitestlink.cn/api/health"

echo ">>> 部署完成！"
echo ">>> 访问地址：https://aitestlink.cn/"
```

使用方式：
```bash
chmod +x deploy.sh
./deploy.sh
```

## 十、域名与前端配置对应关系

独立域名 `aitestlink.cn` 下前端配置如下：

### 10.1 vite.config.ts — 构建基础路径

生产构建 `base` 为 `"/"`（独立域名，无子路径）：
```ts
base: viteBase || "/"
```

### 10.2 BrowserRouter — 路由基础路径

在 `frontend/src/main.tsx` 中，独立域名无需子路径：
```tsx
const basename = import.meta.env.VITE_BASE_PATH || "";
```

### 10.3 API 请求地址

在 `frontend/src/shared/config/deploy.ts` 中：
```ts
export const BASE_PATH = rawBase.replace(/\/$/, "");
export const API_BASE = BASE_PATH ? BASE_PATH + "/api" : "/api";
```

独立域名下 `BASE_PATH` 为空，`API_BASE` 为 `"/api"`，Nginx 将 `/api/` 转发到后端。
